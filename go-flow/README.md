# GO Flow — лендинг для специалистов

Статичный лендинг без сборки и внешних зависимостей. Все пути относительные, поэтому работает в любой папке, например `murx.io/go-flow/`.

## Как разместить

Скопируйте содержимое папки `go-flow/` на хостинг в каталог `go-flow`:

```
go-flow/
  index.html
  privacy.html      ← заглушка, заменить текстом от юриста
  consent.html      ← заглушка, заменить текстом от юриста
  assets/styles.css
  assets/app.js
  README.md         ← можно не загружать
```

Откройте `https://murx.io/go-flow/` (со слешем на конце). Если сервер отдаёт `/go-flow` без слеша, включите редирект на `/go-flow/`.

## Настройки (`assets/app.js`, блок CONFIG)

| Параметр | Что делает |
|---|---|
| `demo` | `true` — жёлтая плашка сверху и подсветка значений ⚑, которые нужно подтвердить. Перед запуском поставить `false`: пометки скроются |
| `formEndpoint` | URL, куда уходит анкета (POST JSON, два запроса: `stage: step1` и `stage: step2`). Пусто — данные никуда не отправляются |
| `ymId` | Номер счётчика Яндекс Метрики |
| `vkPixelId` | ID пикселя VK Ads |
| `tgUrl` | Канал или бот с проектами |
| `cabinetUrl` | Кабинет GO Flow для экрана «Проходит» |
| `analyticsAfterConsent` | `true` — Метрика и пиксель грузятся только после «Понятно» в cookie-баннере |

Проекты, направления и офферы правятся там же, в массивах `PROJECTS`, `DIRS`, `OFFERS`.

## URL-параметры

- `?dir=python|go|dotnet|react|angular|sa|ba` — заголовок, стек, карточки и поле «Направление» под направление.
- `?v=a|b|c` — оффер первого экрана. Без параметра посетитель случайно получает A или B, вариант запоминается.
- `utm_*`, `yclid` — сохраняются на сессию и уходят вместе с анкетой.

## Цели Метрики и VK

`spec_cta_click`, `spec_form_step1`, `spec_form_submit`, `spec_score_pass`, `spec_score_border`, `spec_score_fail`, `spec_tg_click`, `spec_project_card_click`, `spec_faq_open`.

## Перед запуском

- `demo: false`, подставить реальные проекты и ставки.
- Подключить `formEndpoint` к хранилищу на серверах в РФ (152-ФЗ). Скоринг на странице только для UX, его нужно продублировать на бэкенде.
- Заменить `privacy.html` и `consent.html` текстами юриста.
